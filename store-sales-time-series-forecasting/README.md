# <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Telegram-Animated-Emojis/main/Objects/Shopping%20Cart.webp" alt="Shopping Cart" width="30" height="30" /> Store Sales Time Series Forcasting

This project works on predicting sales for Favorita grocery stores in Ecuador using the Kaggle Store Sales competition.    
The goal is to build machine learning models that forecast future sales based on historical sales data, promotions, store characteristics, holidays, and oil prices.      

**Looking forward to working on**:
- Processing time-series data    
- Relating different data, such as holidays, promotions etc    
- Experimenting with models and their evaluation
